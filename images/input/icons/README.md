# Icon input folder

This folder contains the SVG icon set used throughout ExerFit. You can replace an icon with your own SVG while keeping the same filename.

- `nav-home.svg`, `nav-tracker.svg`, `nav-goals.svg`, `nav-history.svg`, `nav-settings.svg`, `nav-profile.svg` are the default navigation icons.
- Files ending in `-active.svg` are used when a navigation item is selected.
- `icon-menu.svg`, `icon-search.svg`, `icon-gps.svg`, `icon-settings.svg`, `icon-edit.svg`, `icon-trash.svg`, `icon-close.svg`, `eye-open.svg`, and `eye-closed.svg` are supporting controls.

Use clean SVG files with a 24×24 viewBox and transparent backgrounds for best results.
