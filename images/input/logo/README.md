# ExerFit logo assets

The two supplied transparent PNG logo marks are used throughout the site:

- `exerfit-logo-light-mode.png` is the dark green mark used on light backgrounds.
- `exerfit-logo-dark-mode.png` is the bright green mark used on dark backgrounds.

The authenticated app automatically swaps between these files when the light/dark theme changes. The landing and sign-in pages use the bright logo over their dark photo backgrounds.
